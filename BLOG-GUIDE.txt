BLOG PUBLISHING — SETUP & HOW-TO
================================

Once set up, publishing a blog post works like this:
  1. Open https://YOUR-SITE.netlify.app/admin
  2. Log in with GitHub
  3. Click "New Blog post", write it, add a cover image, click Publish
  4. About 1 minute later the post is live at /blog/<post-url>.html,
     on the Blog page and in "Latest articles" on the homepage.
You never need to touch the code again.

Each post automatically gets: its own page, SEO title + meta description,
Google article markup (BlogPosting), social share preview (Open Graph),
canonical URL, sitemap.xml entry, reading time, and "More articles" links.


ONE-TIME SETUP (about 20 minutes, all free, all in the browser)
---------------------------------------------------------------

STEP 1 — Put the site on GitHub
  a. Create a free account at https://github.com
  b. Click "+" (top right) > "New repository". Name it e.g. aveeke-portfolio. Click Create.
  c. On the new repository page click "uploading an existing file".
  d. Open this portfolio folder on your computer, select EVERYTHING inside it
     (admin, content, images, all .html files, styles.css, script.js, build.js,
     package.json, netlify.toml, posts-data.js ...) and drag it into the browser.
  e. Click "Commit changes".

STEP 2 — Host it on Netlify
  a. Go to https://app.netlify.com and sign up with your GitHub account.
  b. "Add new site" > "Import an existing project" > GitHub > choose your repository.
  c. Leave the build settings as they are (they come from netlify.toml) and click Deploy.
  d. When it finishes you'll get a URL like https://random-name.netlify.app
     You can rename it under Site configuration > Change site name,
     or connect your own domain later under Domain management.

STEP 3 — Let the admin panel log in with GitHub
  a. On GitHub: your profile picture > Settings > Developer settings > OAuth Apps > New OAuth App
       Application name:           Portfolio Blog Admin
       Homepage URL:               https://YOUR-SITE.netlify.app
       Authorization callback URL: https://api.netlify.com/auth/done
     Click Register, then "Generate a new client secret". Keep this page open.
  b. On Netlify: your site > Site configuration > Access & security > OAuth
     > Install provider > GitHub. Paste the Client ID and Client Secret. Save.

STEP 4 — Point the admin panel at your repository
  a. On GitHub open admin/config.yml and click the pencil (Edit) icon.
  b. Change this line:
        repo: YOUR-GITHUB-USERNAME/YOUR-REPO-NAME
     to your real username and repository, e.g.
        repo: aveekepurkait/aveeke-portfolio
  c. Click "Commit changes". Netlify redeploys automatically.

STEP 5 — Done. Open https://YOUR-SITE.netlify.app/admin and log in.

STEP 6 (recommended) — Tell Google about your site
  Add the site in Google Search Console (https://search.google.com/search-console)
  and submit:  https://YOUR-SITE.netlify.app/sitemap.xml
  New posts are added to the sitemap automatically.


SEO CHECKLIST FOR EVERY POST
----------------------------
  [ ] Title includes the focus keyword, ~50–60 characters
  [ ] SEO description is 150–160 characters and makes people want to click
  [ ] Focus keyword appears in the first paragraph and in at least one heading
  [ ] Use "Heading two" for main sections, "Heading three" for sub-sections
      (the title is already the page's main heading — don't add another)
  [ ] Cover image: 1200 x 630 px, JPG/WebP, under 200 KB,
      file name with the keyword (e.g. google-ads-structure.jpg)
  [ ] Alt text describes the image
  [ ] Link to at least one other post or page (e.g. contact.html, skills.html)
  [ ] 800+ words for competitive topics

GOOD TO KNOW
------------
- Posts are stored as files in content/posts/, images in images/blog/.
- Opening blog.html directly from your computer shows a preview list only;
  individual post pages are created when Netlify builds the site.
- Admin login only works for people with access to your GitHub repository.
