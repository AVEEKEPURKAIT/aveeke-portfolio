AVEEKE PURKAIT PORTFOLIO

Open index.html in a browser.

Pages:
- index.html        Homepage — summary of every section with links to the full pages
- about.html, skills.html, tools.html, experience.html, projects.html,
  education.html, blog.html, testimonials.html, contact.html
Skills, tools and projects are stored once in script.js and feed both
the homepage summaries and the full pages.

BLOG: posts are written and published from /admin on the live site — no code
changes needed. See BLOG-GUIDE.txt for the one-time setup (GitHub + Netlify). Experience, education and testimonials
are written in HTML, so update them on both index.html and their own page.

Included:
- Responsive portfolio layout
- Mobile navigation
- Skills filtering
- Project case-study modals
- Blog search and category filters
- Scroll reveal animations
- Contact form that prepares a mailto enquiry
- SEO-friendly title and description

BEFORE PUBLISHING:
1. Replace purkaitaveeke@gmail.com in index.html and script.js with your real email.
2. Replace LinkedIn and WhatsApp URLs with your real profiles.
3. Add your real profile photo in the hero if desired.
4. Replace demo case-study results with verified numbers/screenshots.
5. Upload the folder to Netlify, Vercel, GitHub Pages, Hostinger or your hosting server.

For a true server-side contact form, connect the form to Formspree, Web3Forms, Netlify Forms or your own backend.
